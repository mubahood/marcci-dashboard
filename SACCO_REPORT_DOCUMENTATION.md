# SACCO Family Report Documentation

## Overview
The SACCO Family Report provides a comprehensive overview of an entire SACCO/family organization, including population demographics, financial summaries, program statistics, and performance trends.

## Features

### 1. Population Overview
- **Total Members**: Count of all members in the SACCO
- **Active Members**: Members with "Active" status
- **Status Distribution**: Alive vs Late (deceased) members
- **Gender Distribution**: Male and Female counts with percentages
- **Age Groups**: Members distributed across 5 age brackets:
  - 0-17 years (Minors)
  - 18-35 years (Young Adults)
  - 36-50 years (Middle Age)
  - 51-65 years (Pre-Retirement)
  - 66+ years (Seniors)

### 2. Financial Summary
- **Total Expected**: Sum of all expected contributions across all programs
- **Total Collected**: Sum of all paid contributions
- **Collection Rate**: Percentage of expected amount that has been collected
- **Outstanding Balance**: Amount still owed across all programs
- **Average Collection Rate**: Overall performance metric

### 3. Program Participation
- **Total Programs**: All contribution programs in the SACCO
- **Active Programs**: Currently running programs
- **Total Records**: All contribution records created
- **Payment Rate**: Percentage of records that have been paid

### 4. Collection Status
- **Paid Records**: Count of fully paid contribution records
- **Unpaid Records**: Count of outstanding contribution records
- **Overdue Records**: Count of unpaid records past their due date
- **Overdue Amount**: Total money owed from overdue contributions

### 5. Top Contributors
Lists the top 10 members who have contributed the most, showing:
- Rank (with medals 🥇🥈🥉 for top 3)
- Member name and ID
- Total amount paid
- Number of payment records

### 6. Recent Activity
Shows the last 30 days of payment activity, including:
- Payment date
- Member name
- Program name
- Payment amount
- Payment method

### 7. 12-Month Trends
Displays financial performance over the past year:
- Monthly expected amounts
- Monthly collected amounts
- Monthly collection rates
- Color-coded performance indicators:
  - 🟢 Green: ≥80% (Excellent)
  - 🟡 Yellow: 60-79% (Good)
  - 🔴 Red: <60% (Needs Improvement)

## Access Control

### Admin Users
- Can view reports for any SACCO
- Can select specific SACCO via query parameter
- Can view combined report for all SACCOs

### Regular Users
- Can only view report for their assigned SACCO
- SACCO filter is automatically applied
- Cannot view other SACCOs' data

## Usage

### From Dashboard
Click the "📊 Generate Comprehensive Family Report" button at the top of the dashboard

### Direct URL
```
/sacco-report
```

### With SACCO Filter (Admin only)
```
/sacco-report?sacco_id=1
```

## Technical Details

### Controller
`App\Http\Controllers\SaccoReportController`

### Route
```php
Route::get('sacco-report', [SaccoReportController::class, 'show'])->name('sacco.report');
```

### View
`resources/views/sacco-report.blade.php`

### Models Used
- `Sacco`: Organization details
- `User`: Member information
- `ContributionProgram`: Program details
- `ContributionProgramRecord`: Payment records

### Key Calculations

#### Collection Rate
```php
$collection_rate = $total_expected > 0 
    ? round(($total_collected / $total_expected) * 100, 1) 
    : 0;
```

#### Payment Rate
```php
$payment_rate = $total_records > 0 
    ? round(($paid_records / $total_records) * 100, 1) 
    : 0;
```

#### Age Groups
```php
'0-17' => whereRaw('TIMESTAMPDIFF(YEAR, dob, CURDATE()) < 18')
'18-35' => whereRaw('TIMESTAMPDIFF(YEAR, dob, CURDATE()) BETWEEN 18 AND 35')
'36-50' => whereRaw('TIMESTAMPDIFF(YEAR, dob, CURDATE()) BETWEEN 36 AND 50')
'51-65' => whereRaw('TIMESTAMPDIFF(YEAR, dob, CURDATE()) BETWEEN 51 AND 65')
'66+' => whereRaw('TIMESTAMPDIFF(YEAR, dob, CURDATE()) > 65')
```

## Troubleshooting

### Common Issues

**Issue**: Report shows no data
- **Solution**: Check SACCO assignment for user
- **Solution**: Verify contribution programs exist
- **Solution**: Check database relationships

**Issue**: Wrong SACCO data displayed
- **Solution**: Verify user's sacco_id is correct
- **Solution**: Check admin role assignments
- **Solution**: Clear browser cache

**Issue**: Print layout broken
- **Solution**: Use Chrome for best print support
- **Solution**: Adjust print margins in browser
- **Solution**: Print to PDF first, then print PDF
